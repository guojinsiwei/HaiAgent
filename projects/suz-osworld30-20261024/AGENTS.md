# Experiment constraints
- CPU desktops and external GLM-5.3-Flash API only. No GPU devices or GPU models.
- User authorized 30 identical OSWorld-Verified tasks per arm, 60 fresh runs.
- Each arm/task cumulative CNY 8; new independent total CNY 480 including all roles and preflight.
- Both arms use the same model, action adapter, budgets and limits. Baseline is the OpenCUA execution flow with GLM, not native OpenCUA model weights.
- Retain all original runs. No historical scores substituted into this fresh comparison.
- No GPT automations, no key display, no modification of other users' workloads.
