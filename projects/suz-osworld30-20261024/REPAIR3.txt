Code changes (independent projects/SUZ-repair3)
1. One bounded extra request for transient transport/empty/truncated output, subject
   to the existing all-role shared budget and request cap. Unknown charges stay
   reserved. Reasoning-only text is never executed. No unbounded retry loop.
2. Exactly one line-delimited action code block is parsed; inline backtick prose
   cannot confuse the upstream parser. Missing Action heading is normalized.
   Explicit termination status is canonicalized independently from answer text.
   Literal waits up to 30 seconds are allowed without shortening them. Ambiguous
   multiple action blocks still require a bounded model format repair.
3. Critic checks original task, initial foreground image, current raw image and
   executed actions independently of prior plans/obligations. Missing/effect-
   mismatched evidence blocks completion. Per-obligation review still follows a
   supported audit. Negative audit skips the redundant review call.
4. Each arm/task/attempt has separate preflight and final evaluation caches.
   Only checksum-verified fixture files are copied from the shared asset store.
   Grader outputs are retained per attempt with hashes. Official metrics unchanged.
5. After official setup, wait for each explicitly launched supported GUI application's
   mapped window before capturing the first agent observation. Window metadata stays
   in setup diagnostics and is not sent to the model. Timeout fails before inference.
