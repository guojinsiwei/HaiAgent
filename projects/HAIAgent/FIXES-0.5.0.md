# HAIAgent 0.5.0：探索方向记忆与有界停滞恢复

## 动机

0.4.x 能识别同一命令在同一作用域下反复返回相同输出，也能拒绝无理由重试；但拒绝后只要求模型“换一种方法”。在 LHTB 的显微图像任务中，模型连续 776 次提出同一被拒绝动作，工具循环变成了决策循环。

## 修改

- HAI 动作协议增加可审计的 `strategy` 标签。模型应对同一底层方法复用同一标签。
- 任务上下文增加最多 8 条的 `exploration_history`，记录方向、尝试次数、结果类别、工作区变化、证据编号和精确重复停滞。
- 方向账本与事实记忆分开：方向是模型声明的探索组织信息，不冒充经过证明的事实或语义聚类结果。
- 精确重复触发时，`decision_advice` 同时显示当前方向和最近尝试方向，并要求选择不同原理或信息源，而不是简单重写命令。
- 无 `strategy` 的旧客户端仍可运行，但审计会明确记录标签来自 purpose 或命令族回退。
- 连续 `max_repeat_blocks` 次（默认 3）请求被拒绝的精确重复动作后，以 `stagnation_limit` 停止并保留已有工作区，避免无界模型空转。
- Raw 模式不启用方向账本、重复拦截或停滞熔断。

## 边界

- 组件不会从任意 Bash 文本自动断言两个策略语义等价；当前语义身份主要来自模型稳定标签。
- 工作区变化只记录为 `changed_workspace_unverified`，不等于任务取得进展。
- 本版本解决“发现重复后如何改变决策”的最小闭环，不声称已经实现通用的目标级进展判断。
