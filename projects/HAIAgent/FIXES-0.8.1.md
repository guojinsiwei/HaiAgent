# HAIAgent 0.8.1

本补丁收紧 0.8.0 的语义重复边界，避免把合理的多步探索误判为空转。

- 动作方向保留数字参数，不再把 `--offset 0` 与 `--offset 100` 合并。
- 显式提取行号区间、分页、start/end、offset/limit、skip/count、grep 上下文窗口及 Awk `NR` 范围。
- 搜索模式和稳定参数继续进入方向身份；同一个文件不等于同一种探索。
- 不再单凭“连续多次没有修改工作区”判定停滞。读取或搜索得到不同反馈时保持 `active`。
- 长诊断序列只有在窗口内至多两种反馈循环时才标记 `stalled_low_information_cycle`；连续等价反馈仍按原阈值拦截。
- 新增回归覆盖同一文件不同区间、不同搜索模式、不同 offset，以及连续十个区间返回相同文本仍不触发干预。

该规则有意偏向保守：宁可漏掉仅靠不断改变数字参数伪装的少量循环，也不阻断正常的分页阅读和逐段搜索。真正的工具调用冗余率仍由离线语境审计决定，在线方向检测不能替代该指标。
