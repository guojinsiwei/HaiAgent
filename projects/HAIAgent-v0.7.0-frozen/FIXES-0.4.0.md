# 0.4.0：重复无新增输出的任务内记忆

## 针对本轮真实失败

0.3.0 财务文档任务中，HAI 没有主动提出 memory，自动规则只覆盖重复报错和恢复；OCR 反复退出 0，因此记忆为空。反馈没有丢失。新实现不要求模型先发现并总结自己的循环。

## 机制

- 本地维护最多 16 个动作的有界观察器，以完整命令、cwd、stdin 摘要匹配。匹配的是动作身份，不猜测不同命令语义等价。
- 同一动作第三次得到相同完整 stdout/stderr/退出码时，自动记录带证据的高价值发现。普通单次成功不入库。重复事实合并，不产生几十条相同记忆。
- 输入、输出或已观察到的 scope 改变会重置对应计数；执行导致已知工作区变化、截断、超时、阻断或未知退出码，不用于相同输出判断。
- 环境状态未知时仍保存历史观察，不谎称外部世界未变，不断言任务失败或所有重复均无用。
- 下一轮 context 中保留紧凑 decision_advice，即使完整记忆被预算压缩。输出原文不在观察器重复存储。
- HAI 若继续选择匹配动作，需要 retry_reason（16..400 字符）说明新证据预期、必要复测或有限轮询；缺少理由时不执行该工具，反馈一次纠正，仍计入交互轮次。无隐藏模型调用，无额外轮次预算，无自动任务重试。
- 有理由的重试仍允许。程序不能证明理由真实或保证模型改用正确方法；这属于需要实验检验的剩余限制。
- 提交权仍由模型掌握。Raw 没有 HAI 的记忆、decision_advice 或重试理由门控，其他执行器、模型和预算共用。

## 观测与科研边界

日志新增 automatic_memory、repetition_observed、repeat_decision，request_context 记录 selected_memory_ids 和 decision_advice_visible，可区分生成、选择和动作干预。

成功率、交互轮次和语境工具调用冗余率定义不变。本地“相同输出重复”只是触发信号，绝不能替代科研冗余率。没执行的动作不算工具调用，但仍算交互轮次。

这是“自动记忆 + 决策提示 + 重试理由检查”的联合版本；若有收益，不能未经消融声称只由记忆带来。没有引入针对 PDF/OCR 题目的答案、专用策略或隐藏测试信息。复杂 bash 仍保守分类为 generic，新观察器不依赖该分类，不试图不安全地解析任意 shell。

0.3.0 云端实验已停止封存；0.4.0 使用相同 6 题、两组各 6 次，从干净环境重新运行，不混合旧结果。
