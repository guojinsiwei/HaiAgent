Recuris 和 TACO 按现有适配范围推进：Recuris 使用冻结版本，TACO 使用题内演化版本。复现说明需写清与原方法的差异。

## 一起修改代码

1. 开始前先同步 `main`，再为本次修改建立分支，例如 `lizehao/exploration`、`huoyankai/benchmark-runner` 或 `lutianyu/taco-adapter`。
2. 一次提交集中处理一个问题，说明改了什么、为什么改。
3. 完成后提交 Pull Request，写清运行方法和检查结果。合并前请另一位同学看一下。
4. 合并后，其他人同步最新 `main`，再继续自己的工作。

小任务和待处理问题记在 Issues 中，标明负责人。遇到代码冲突一起确认保留内容。

## 实验记录

每轮实验记录代码版本、模型、题单、参数和预算。结果保留任务编号、官方评分、运行状态及费用。环境错误、评分失败和算法未通过分别记录；补跑记录原因，不覆盖原结果。

API 密钥、个人配置、依赖目录、容器镜像和大体积原始日志保存在各自环境或约定的实验存储中。仓库提交配置示例、运行脚本、结果摘要和原始记录的存放说明。
