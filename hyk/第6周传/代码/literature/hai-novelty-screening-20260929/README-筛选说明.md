# HAI / BestFGS 相关工作筛选包

本资料包包含 12 篇重点论文和 1 篇 Agent Memory 综述。筛选目标不是判断论文是否泛泛地使用了“记忆”，而是确认下面这个完整技术组合是否已经被实现：

> 在单个长程 CLI 任务内部，从终端反馈中在线提取细粒度操作经验；把经验表示为带适用条件、证据、失败原因、依赖和替代方向的结构化记忆；根据当前终端状态和候选动作进行匹配；在动作执行前影响探索，并使用 Bash 感知的规则压缩上下文；整个机制可以作为不修改底层模型的即插即用组件。

## 建议阅读顺序

1. `01_MACE.pdf`：条件—动作—输出功能单元、support/conflict/repair 关系，是最接近当前构想的工作。
2. `02_Agent_Workflow_Memory.pdf`：在线/离线提取并复用工作流。
3. `03_ReSum.pdf`：长程交互中的上下文压缩与持续探索。
4. `04_Devils_Advocate.pdf`：替代方向、动作后评价和回溯。
5. `05_SWE_Search.pdf`：多智能体、MCTS、文字反馈和软件任务探索。
6. `06_Dream_RSI.pdf`：历史探索树、replay simulator 与探索策略改进。
7. `07_Reflexion.pdf`：文本反思与 episodic memory 经典基线。
8. `08_ExpeL.pdf`：从历史任务提取自然语言经验。
9. `09_Voyager.pdf`：环境反馈、自验证与可执行技能库。
10. `10_Hindsight.pdf`：结构化 retain/recall/reflect 记忆架构。
11. `11_REMem.pdf`：混合记忆图和迭代检索推理。
12. `12_MiTa.pdf`：多智能体任务分配与 episodic memory 汇总。
13. `13_Memory_in_the_Age_of_AI_Agents_Survey.pdf`：用于建立术语和相关工作边界。

## 每篇论文需要填写的字段

- 记忆范围：任务内、跨任务、跨会话；
- 记忆单元的数据结构；
- 写入、合并、遗忘和压缩机制；
- 检索依据：任务、环境状态、候选动作或失败模式；
- 记忆如何真正改变下一动作，而非仅拼接提示词；
- 是否显式保存已尝试/失败的探索方向；
- 是否有 CLI/Bash 特定的环境表示或压缩；
- 是否能作为底层模型无关的即插即用组件；
- 是否在同一任务中在线形成并立即复用；
- 与本课题完全重合、部分重合、尚未覆盖的部分；
- 创新威胁等级及对应论文页码、公式、伪代码和代码位置。

最终建议输出一张 novelty matrix，并分别给出“已经被完整做过”“仅有单模块重合”“尚未发现完整实现”三类结论。
