# Reliability v17 — 独立修复副本

本目录包含 BestFGS 0.17.0、HAIAgent 0.5.0，以及 LHTB 适配器的修复候选。
它不覆盖桌面项目、旧版冻结目录或云端正在进行的实验；不能把新旧版本的结果混算。

## 修复内容

1. **候选交付**：完整公开检查必须没有显式失败输出。零退出码不能掩盖失败摘要；评估角色判定失败的转移不能登记为已验证候选。候选内容改变会撤销验证资格。
2. **保底选择**：不再仅按最新登记选择。对同一组公开验证命令、同一明确的 `Normalized` 高分优先输出，允许非退化候选替换保底；同分或不可比较则保留已有保底。模型仍能显式提交其他符合提交契约的候选。这不是对任意任务分数的通用理解，也不是官方成功判断。
3. **预算耗尽交付**：检查点记录快照指纹。LHTB 截止时间回退只使用属于本次实验、内容仍与指纹一致的候选，不额外调用模型或工具。存在完整草稿但未通过验证时仍可交给外部评测，绝不标记成功。
4. **重复检测**：工作目录是命令身份的一部分，但上下文投影时改变 cwd 不再清空全部历史；真正 workspace/environment 版本变化仍清空。`/app` 别名由拥有它的 LHTB 适配器映射，不把任意绝对路径当成安全目录。
5. **有界恢复**：第三次相同输出形成提醒，之后重复请求需理由；每个命令/输出/作用域最多两次有理由的追加尝试。第二次连续拒绝时给出策略重置提示，六次连续拒绝后以 `stagnation` 停止。换策略后可继续，不增加隐藏 API 调用、不重置总预算、不强行声明成功。
6. **记忆减负**：稀疏增量、最多四条/字段、两条经验/退休更新、6000 字符硬界；记忆请求最多 1536 输出 token，传输及格式尝试各一次。相同未变工作区的重复观测跳过可选记忆更新。输出格式失败保留评估和旧上下文并记录 deferred；网络、鉴权、余额等未知传输故障仍抛出，不静默掩盖。
7. **审计**：保留三角色用量、记忆跳过/延后次数、恢复阶段、候选指纹；适配器区分明确延后的记忆输出错误与传输故障。保留 LHTB 二元拒绝后的同会话续跑钩子，不重置预算。

## 使用边界

- 成功率、工具冗余率等研究指标定义没有修改。`stagnation` 是失败/停止原因，不是成功。
- 不读取隐藏答案，不按任务 ID 特判，不自动运行新实验，不使用真实模型 API 做本地回归。
- `validation.py` 是已知公开输出格式的保守失败拦截器，不是通用语义验证器。对其他模拟器/评分程序仍应编写任务适用、失败返回非零的断言；模型评估亦不等于官方正确性。
- 恢复提示能被送达、无效尝试能被限制，不保证真实模型一定换出正确策略。
- `lhtb-adapter` 是从旧实验适配器复制的开发副本。旧准备/启动脚本仍带历史协议路径，**不要直接执行其旧 launch/control/prepare 脚本启动实验**。部署前需在新的运行目录生成题单与源码哈希，验收 Docker 导出及二元续跑；当前活跃实验不切换代码。

## 本地验证

运行 `python verify.py`；Python 3.11+、Git 可用即可。测试主要使用临时目录、脚本化模型和本机回环 HTTP 测试服务器，不访问付费模型服务。
测试日志保存到本目录。完整 BestFGS 测试较多；`python verify.py --quick` 只跑定向核心回归。
