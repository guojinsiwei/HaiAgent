Behavior
- LeanConfig.expectation_enabled defaults to True in this independent candidate.
  Set it to False for the original prompt/execution path, without expectation
  inspections, feedback or counters. No other switch/default/budget was changed.
- The actor is instructed to attach one concise expected_observation to run.
- Supported kinds: build, public_test, file_state, output, explicit unknown.
- Register the contract before dispatch; associate the review with the actual
  command key and E-number, then return it in evidence.expectation to the actor.
- File observations use the existing public dependency-state interface, reusing
  already observed values when available. They do not run another task command
  or introduce another model request. Public paths are task-root-relative.
- Outcomes are matched, contradicted, unknown. Timeout, blocked execution,
  incomplete capture/status coverage and uncertain file state stay unknown.
- Missing/invalid expectations produce bounded unknown feedback and counters;
  they do not add protocol errors, regeneration requests or a new action gate.
- Build matching requires recognized build invocation, clean execution and a
  new/changed artifact. Unchanged existing artifacts are insufficient evidence.
- public_test uses the preexisting supported result parser (currently narrow
  explicit pytest summaries). Unsupported test runners/QEMU tests return unknown
  here; they may declare a concrete output observation instead. Output matching
  never upgrades a tool result to a validated test pass.
- Error absence alone is not a positive output assertion. Conflicting positive
  and negative markers return unknown. File change alone is not task progress.
- A mismatch does not invalidate a route or automatically admit failure memory.
  A match does not certify task success or automatically create a checkpoint.
- No change to orthogonal similarity rules, repetition blocking, monitor/advisor
  trigger/cooldown, memory policy, restoration, RAW or the existing two-candidate
  prediction switch. contrastive_predictions is NOT turned on by this addition.
