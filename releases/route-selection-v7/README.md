# BestFGS 路线选择 v7（独立对照实验版本）

在 v6 的可靠监控、工具反馈和执行记录基础上，加入真正执行的有界路线探索。
不覆盖 `monitor-control-v6`，不改旧实验结果，不修改 HAI 算法。

## 改变的决策机制

连续相同命令/状态/输出，或语义监控发现停滞时，Actor 预注册一次 `route_experiment`：
两个竞争假设、一个区分探针、每个假设的支持/反驳观察、各自 1–3 步候选修改，以及同一公开检查。
本轮附带的普通 run 不执行，防止计划被接受后又偷偷做另一件事。

控制器随后在原预算内执行：

1. **建立共同起点**：保存当前文件检查点。在原状态执行公开检查；若已通过，或无法判定，
   不盲目试做。失败/通过标记和检查命令事先固定，不能看了候选结果再改评分标准。
2. **区分实验与条件淘汰**：执行探针。仅当捕获完整、执行干净且支持/反驳标记不冲突时，
   才按预注册预测标记支持或反驳；其余保持 unknown。条件上被反驳的候选不占用修改预算。
3. **独立试做**：未淘汰的候选分别从同一检查点出发。探针没有分辨力时允许试两条路线，
   不凭主模型的信心直接选一个。第二条路线不继承第一条的文件修改。
4. **同检查比较**：每条路线修改后执行相同检查。只有原检查失败、候选检查通过且目标文件
   确有改变，才算本次公开检查有改善；同样通过时选工具成本更低者，同成本按试探顺序。
5. **恢复选中状态**：恢复有改善的候选；都没有改善则恢复原状态。预算中途结束时优先保留
   已完成验证的候选，否则恢复原状态。恢复失败明确报告基础设施错误，不伪装成功选路。

这不是只在提示词里添加“换思路”。控制器负责命令调度、分支隔离、比较和恢复。
它也不是通用大规模 Best-First/MCTS：当前每个停滞点最多两个候选、至多三轮探索。

## 记忆如何影响决策

新增 `route-memory.json` 保存条件工作区、假设、探针/基线输出身份、尝试动作证据、检查结果和选择结果。
这与普通自然语言经验库分开，最多 12 条，Actor 热上下文最多显示 4 条。

对于同一候选程序、同一工作区、相同当前探针和基线观察，过去明确失败/被预测反驳的路线
不再进入本轮自动试做。假设换个说法不会清除该记录。当前观察或工作区改变时重新评估，
不会把一次失败变成无条件永久禁令；普通 Actor 操作仍可重新检查适用性。

## 预算与边界

- 默认每轮最多 10 个工具、每条路线 1–3 步，每个命令最多 15 秒；单轮墙钟最多 180 秒，
  并保留至少 30 秒任务剩余时间。新一轮至少需 120 秒剩余时间、3 个快照名额和足够工具名额。
  已有预算紧张就不启动；最多 3 轮，两轮之间至少间隔 12 个正常工具步骤。
- 所有实验工具计入原有 600 次上限；快照计入原有 12 次上限；模型调用、监控、时间上限不增加。
  最多两次要求补充有效计划，随后释放回普通执行，不无限拦截 Actor。
- 新功能沿用现有 Actor 与 Monitor，没有新增模型角色。控制器自动执行已注册命令，
  不为每个内部步骤额外请求 Actor；真实 token/时延/快照开销必须在对比实验中一起报告。
- 探针与检查必须不改变可观察工作区；否则结果无效并恢复。嵌套进程、网络、外部服务状态
  不能靠文件检查点回滚。方案应限于任务授权范围内、可恢复的小规模本地实验。
- “支持/反驳”只相对于模型预注册的预测，不证明真实因果关系；字面匹配也不等于通用语义判断。
  两条路线是否实质不同仍依赖模型；程序仅排除明显相同的命令/假设/预测。
- 检查仍由模型提出，可能不充分。基线对照防止把无条件打印成功算成收益，但不能证明检查
  覆盖了全部要求。`route_selected` 和公开检查改善**不是官方任务成功率**。
- 固定两候选及短命令预算是本版本的可检验算法假设，不能据此预先宣称优于 v6。

## 开关与对照

v7 CLI 和 `integration/transport.py` 默认 `route_search=True`；底层 `LeanConfig()` 为兼容
旧调用默认关闭。直接构造时同时开启 `stagnation_control` 与 `outcome_reliability`，并至少
保留 3 个活动检查点。开启 v7 时路线控制取代 v6 的单恢复计划门控，前两项可靠性修复保留。

- 正式对照：冻结的 **v6** 对 **v7**，同一组题、镜像、模型与逐题预算，独立干净工作区。
- 同代码消融：v7 使用 `--no-route-search` 或适配器 `route_search=False`，恢复 v6 决策路径。
- 对照配置见 [comparison-plan.json](comparison-plan.json)，当前是准备状态，**未启动付费实验**。
  不应拿新的 v7 分数直接和旧 v5 十二题结果当作公平消融。
- 若使用之前 12 题，保留原逐题 3600/5400/10800 秒预算和双方一致的交付预留，不能全部改成一小时。
