# 撤下独立 LLM 结果审计

- 保留 Notebook 运行后端及现有图搜索、压力、记忆、快照和最终复验，不整体回滚项目。
- CLI / SWE-bench / Terminal-Bench 主入口默认且仅允许 Judge off。
- CLI 移除审计客户端的创建路径；不读取任何 Judge 环境变量或产生额外审计请求。
- Notebook 配置和恢复指纹移除 Judge 环境变量；旧审计服务 URL 不会阻碍新实验启动。
- 恢复运行时原有 off 判定：真实候选变化、执行门槛、功能验证和求解模型整理的达标项。
  模型自报 task_success 在默认验证模式下仍不能直接成为成功；交付前最终复验保留。
- Judge 模块/显式库级测试留作历史实验兼容，不属于当前实验运行链路；输出兼容字段保留。
- 新旧判定配置产生不同代码/配置指纹。请使用新 run-id / output-root，勿混用旧实验结果。
- 此次不改变求解模型服务商；dashscope 若被选为求解器仍可用，但不担任结果裁判。

结果仍分内部诊断与官方评测；Notebook 不支持嵌套 Docker，官方评测限制未改变。
